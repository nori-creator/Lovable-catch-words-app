# 単語詳細・復習・写真編集UIの改善計画

## 目標
単語学習画面の読みやすさを保ちながら、誤表示と画面端の崩れを直し、写真を直感的に編集できる状態にします。

## 実装内容

### 1. 復習の4択
- 解答後も背景画像をそのまま維持します。
- 発音記号や解答情報が画像上へ崩れて重ならないよう、結果表示を独立した不透明領域に固定します。
- 正解・不正解、発音、次へ進む操作は現在の動作を維持します。

### 2. 頻度・使う場面
選択された「Modern card layout v3」を、現在の単語詳細の濃紺・青系デザインへ合わせて実装します。

- 使用頻度：5分割グラフと説明ラベル
- 言葉の性質：`話し言葉 — 中立 — 書き言葉` の3区分グラフと現在位置
- 使用場面：最大4カテゴリーをスマホ幅でも横一列に収める
- 長いカテゴリー名は文字サイズと省略表示を調整し、枠外へ出さない

### 3. 台湾華語チャンク
- 英語ではなく繁体字の台湾華語チャンクを表示します。
- 現在の品詞色分け（名詞・動詞・状態動詞/形容詞など）をそのまま踏襲します。
- 各チャンクの直下に日本語訳を必ず表示します。
- 既存データに訳がある場合はそれを使い、欠落時も表示構造が崩れないようにします。

### 4. 写真の長押し編集
- ホームの写真を長押しすると、iPhoneのアイコン編集に近い揺れで編集状態へ入ります。
- 写真そのものをドラッグして並べ替えられるようにします。
- 角のハンドルを引く操作で、許可された段階サイズへ直感的に変更できるようにします。
- ドラッグ直後の誤タップ遷移を防ぎ、完了操作で位置とサイズを保存します。
- 単語詳細での写真変更は、その画面に留まる既存挙動を維持します。

### 5. 画面端と設定スイッチ
- 設定のON/OFFスイッチの丸を縦中央へ補正します。
- 図鑑の日付欄に右側の余白と幅制約を設け、スマホ幅で右端が見切れないようにします。
- カテゴリー・日付の選択メニューが画面内へ収まる既存挙動も確認します。

## 確認
- スマホ幅で、4択の回答前後、単語詳細、ホーム写真編集、設定、図鑑の日付欄を実画面確認します。
- 台湾華語チャンク、品詞色、訳、4カテゴリー一列、2種類のグラフを確認します。
- 関連テストと型検査を実行し、既存の復習・図鑑・写真保存動作に影響がないことを確認します。
