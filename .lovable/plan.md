# 図鑑追加のプレミアム祝福・着地体験

## 目標
「図鑑に追加」を、保存処理の待ち画面ではなく、収集した達成をしっかり味わえる約3秒の儀式にします。

既存の「浮上 → 拡大 → 発音 → 図鑑へ移動 → 棚に着地」という骨格を活かしつつ、暗い画面と単純な光から、白を基調にした上質な祝福シーンへ刷新します。特定作品の表現を複製せず、「道具・収集物を一つずつ主役として紹介する間と高揚感」をオリジナルの演出で実現します。

## 体験シーケンス

1. **持ち上がる予兆（0–450ms）**
   - 押した瞬間に保存状態へ移り、元の画像がごく小さく沈んでから、影を床に残してふわりと浮上します。
   - 背景の情報量を静かに落とし、視線を画像へ集めます。
   - 軽い触覚と短い上昇音を同期させます。

2. **白い展示空間への転換（450–1,050ms）**
   - 画像の背後から白い面が円形ではなく柔らかく全面へ展開し、画面を白い展示空間へ切り替えます。
   - 画像は縦横比を保ち、端末の短辺に収まる最大サイズまで広がります。写真も切り抜きも粗く引き伸ばしません。
   - 強いフラッシュや派手な虹色は避け、薄い金属光・柔らかな影・一度だけ走る細いハイライトで質感を作ります。

3. **単語の紹介と祝福（1,050–2,250ms）**
   - 画像を完全に静止させ、単語、読み、短い「図鑑に追加」の祝福表示を順に現します。
   - 単語の発音をこの静止点で再生し、音を聞く間は他の動きを抑えます。
   - 周囲には少数の紙片ではなく、細い光の粒・小さな輪・柔らかな放射線を疎密付きで展開します。中心から全部同時に出さず、左右非対称の時間差で自然な高揚を作ります。
   - 発音、祝福音、触覚は競合させず、単語の音声を主役にします。端末の音量・触覚設定を必ず尊重します。

4. **図鑑への受け渡し（2,250–2,700ms）**
   - 白い展示空間の画像が少し持ち上がり、次画面の棚へ続く方向へ抜けます。
   - 画面切替は暗転や瞬間消去を挟まず、白い余韻を保ったまま図鑑へつなぎます。

5. **正しい棚へ着地（2,700–3,500ms）**
   - 図鑑を必ず棚表示で開き、保存された単語のカテゴリーと棚を自動で特定します。
   - 以前の絞り込みが対象を隠す場合は一時的に解除し、対象カテゴリーまで即座に位置合わせします。
   - 棚の対象位置を先に柔らかく照らし、画像が上から落ち、接地直前にわずかに減速して「ドン」と収まります。
   - 接地時だけ棚板の短い沈み、接地影の圧縮、周辺アイテムのごく小さな反応、低い着地音、重めの触覚を同期させます。
   - 着地後は画像を安定させ、カテゴリー名と追加結果が読める状態で終了します。勝手に詳細画面へ進みません。

## 統一する追加経路
- カメラ撮影からの追加
- スキャン候補からの追加・再会キャッチ
- 文字・音声入力からのゴースト追加（実写がない場合は仮画像を主役にする）

どの入口でも同じ祝福シーケンスを通し、保存成功後の演出失敗を「保存失敗」と誤表示しない既存の安全策は維持します。

## 視覚・音・触覚の品質基準
- 白、墨色、控えめな金の3役を中心にし、多色の紙吹雪・過剰な発光・連続バウンド・大きな「GET!」は使いません。
- 画像そのものを常に最も強い要素にし、装飾は画像の輪郭や着地を補助する範囲に留めます。
- 動きは「軽い浮上」「静止して聴く」「重い着地」で質量を使い分け、全工程を同じイージングにしません。
- 祝福音は既存の音量設定、触覚は既存の触覚設定に従います。
- `prefers-reduced-motion` では大きな移動・拡大・粒子を省き、白への短いクロスフェード、発音、結果表示、控えめな着地強調に置き換えます。

## 実装方針
- 既存の共通キャッチ演出を新しい標準版へ更新し、演出の状態とタイミングを一箇所で管理します。
- 祝福用の背景、画像、単語、読み、光の粒、進行状況を共通オーバーレイとして構成します。
- 発音の事前取得を各入口で行い、祝福の静止点から遅れず再生できるようにします。
- 既存の開発者向けエフェクト比較機能には新しい版を追加し、過去版は壊さず残します。
- 図鑑側は追加されたIDからカテゴリー・棚を確定し、表示形式、絞り込み、スクロール位置、着地開始を同期させます。
- 棚の着地は固定の待ち時間だけに依存せず、対象セルが描画されたことを確認して開始します。
- ハーネスに「祝福の主要な静止点」と「棚への着地状態」を追加し、実データ不要で毎回見た目を比較できるようにします。

## 確認項目
- iPhone相当の縦画面とAndroid相当の縦画面で、画像・単語・読みが切れず、下部操作にも重ならない。
- 写真、切り抜き、仮画像、画像なしの各ケースで破綻しない。
- 日本語UI、繁体字・注音、英語の長い単語で文字が画面外へ出ない。
- 発音が祝福の静止点で一度だけ鳴り、音量オフでは祝福音も鳴らない。
- 対象カテゴリーが以前の絞り込みで隠れず、正しい棚・正しいセルに一度だけ着地する。
- 保存済みなのに演出だけ失敗した場合も重複追加を誘発せず、図鑑へ到達する。
- 動きを減らす設定で大きな飛行や点滅が発生しない。
- 実機相当の表示をスクリーンショットと操作確認で検証し、既存テスト・画面検査も通す。
