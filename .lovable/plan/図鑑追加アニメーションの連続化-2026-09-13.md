# 図鑑追加アニメーションの連続化

## 目標

「図鑑に追加」を押した指の反応から、写真図鑑の該当カテゴリーへ収まるまで、同じ画像が途切れず動く一連の体験にします。

```text
押す
  → 画像がきゅっと沈む
  → 弾むように浮上し、弧と傾きを伴って画面いっぱいへ広がる
  → 単語表示と発音を同時に開始し、1秒だけ静止
  → 図鑑が画像の背後に開く
  → 該当カテゴリーの空欄へ減速しながら飛び込む
  → ドンッと接地し、1回だけ小さくバウンスして定着
```

本棚表示は戻さず、現在の写真図鑑のカテゴリー内に着地させます。

## 実装内容

### 1. ボタンを画像の直下へ移動

- カメラ撮影、スキャン候補、文字・音声入力の確認画面で、「図鑑に追加」ボタンを画像のすぐ下へ配置します。
- メモ、自撮り、単語詳細などはボタンより下に残し、追加の主操作と画像の関係を明確にします。
- 保存中は連打を防ぎつつ、画像は押した瞬間から反応を始めます。

### 2. 画像だけを起点にした動きへ刷新

- 現在の光輪、粒子、全画面へ消える動きを標準経路から外します。
- 画面内にある実際の画像の位置・大きさを測り、その画像の見た目を引き継いだ1枚だけを動かします。
- 押下直後の圧縮、初速の強い浮上、緩い弧、わずかな回転、遅れて伸びる影、画面中央での1回のオーバーシュートで「軌跡」と質量を見せます。
- 縦長・横長・正方形・透過画像で、画面からはみ出さず最大限大きく見える収まり方を分けます。

### 3. 単語と音声を完全同期

- 画像が最大サイズへ達したフレームで、画像の直下に単語を焦点が合うように表示し、同時に発音を開始します。
- この状態だけを正確に1秒保持します。それ以外の区間では、画像・影・背景のいずれかが常に動いている状態にします。
- 発音音声は確認画面で先読みし、ボタン押下時に音声利用を有効化して、表示との遅れを最小化します。
- 読みは補助情報として単語の下に置き、「図鑑に追加」の重複表示は演出中に出しません。

### 4. 画面をまたぐ同一画像の連続移動

- 認証済み画面全体に、ページが変わっても消えない共通の演出レイヤーを置きます。
- 保存と浮上を並行させ、保存が早い場合も遅い場合も動きが途切れない状態機械にします。
- 保存成功後、画像を最大表示のまま保ちながら図鑑を背後に開きます。ルート変更で画像を作り直したり、画面上へ一度消したりしません。
- 保存に失敗した場合は着地させず、画像を元の位置へ短く戻して再試行可能にします。保存成功後に音声や演出だけ失敗した場合は、保存失敗とは表示せず図鑑へ確実に移します。

### 5. 実際の該当セルへ着地

- 図鑑側は追加されたIDからカテゴリーを確定し、検索・日付・カテゴリーの絞り込みを解除または該当カテゴリーへ合わせます。
- 他の画像を先に通常表示し、新しいセルだけを空欄として予約します。
- 予約セルの実座標を測り、共通レイヤー上の画像をその位置と大きさへ直接飛ばします。
- 接地直前に空気抵抗で減速し、最後だけ重力で落下。接地時に縦圧縮、横復元、1回の小さな跳ね返り、静止の順で物理感を作ります。
- 接地と同じ瞬間に低い着地音・強めの触覚・短い影の広がりを同期し、周囲の近い画像だけが距離に応じてごく小さく揺れます。

## 技術方針

- 新しい重量級ライブラリ、動画、Canvas、3Dは不要です。既存の Web Animations API で、`transform` と `opacity` を中心にGPU合成し、60fpsを狙います。
- 現在の問題は描画能力ではなく、追加画面と図鑑で演出が分断されている構造です。共通レイヤーとFLIP方式（開始位置と着地点の実測）へ変えることで解決します。
- アニメーションは `press → lift → reveal → route-ready → flight → impact → settle` の状態で管理し、二重再生、戻る操作、画面回転、遅い保存を安全に処理します。
- 端末の「動きを減らす」が有効なら、大移動・回転・バウンスを省き、短い拡大、単語と発音、着地点の強調へ置き換えます。

## 検証

- 411×777を基準に、狭い端末、縦長端末、標準画面でボタン位置と全シーケンスを確認します。
- カメラ撮影、スキャン候補、文字入力、音声入力、再会の各経路で同じ演出になることを確認します。
- 保存が即時・1秒・3秒・失敗、音声取得失敗、連打、画面回転でも、二重保存・画像の瞬間移動・操作不能が起きないことを確認します。
- 開始画像と飛ぶ画像の位置差、最大表示時の単語位置、図鑑セルとの終点差を画像比較で確認します。
- 発音開始と単語表示、着地と音・触覚の同期を時刻記録で確認します。
