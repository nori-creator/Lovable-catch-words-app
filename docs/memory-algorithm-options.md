## いまの仕組み（出発点）

| 部分                | いまのやり方                                                                                                          | 場所                          |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| 次にいつ出すか      | **SM-2 の簡略版**（1回目 1日 → 2回目 3日 → 以降は前の間隔 × 覚えやすさ）。採点は 1〜5。遅れて思い出せた日数も一部足す | `src/lib/srs.ts`              |
| いま何%覚えているか | 指数の忘却曲線 `R = exp(−経過日数 / 安定度)`。安定度は「出題日にちょうど 90% になる」ように合わせてある               | `src/lib/srs.ts`              |
| 記憶の状態（6段階） | いまの % だけで決める（30 / 50 / 70 / 85 / 95% で区切り、「忘れかけ」〜「はっきり」）                                 | `src/lib/memory.ts`           |
| AI の予測（Jev）    | 裏で予測だけ記録している（影の運用）。出す日には使っていない                                                          | `src/lib/jev-tasks.server.ts` |

**いまの弱いところ**

- **状態が「いまの %」だけで決まる。** スクショでは 135 語のうち 130 語が「覚えている」か「はっきり」（85% 以上）で、差がほとんど見えない。昨日覚えた語と、半年もっている語が同じ色になる。
- **SM-2 は 1987 年の決め打ちの式。** 人ごと・語ごとの忘れ方をデータから学ばない。

## A. 記憶の状態の分け方

| 案                                | 分け方                                                                                                                                | 良い所                                               | 弱い所                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------- |
| **S1（いま）**                    | いまの % で6段階                                                                                                                      | 「今日やるべきか」が分かる                           | ほとんどの語が同じ段に固まる。毎時間 % が動く |
| **S2: 強さで3段＋「要復習」の印** | 安定度（何日もつか）で **新しい（7日未満）／育ち中（7〜30日）／定着（30日以上）**。別に「今日の復習が要る（90% を切った）」印を付ける | 時間とともに語が「育つ」のが見える。続ける動機になる | 段が上がるのに数週間かかる                    |
| **S3: 学習の段階で4つ**           | **はじめて／練習中／復習中／忘れた（直近で間違えた）**（Anki と同じ考え方）                                                           | 何をすればいいかが直感的                             | 「どれくらい覚えているか」の量は出ない        |

**おすすめ: S2。** 「今日やる語」は % の印で、「育っている感じ」は強さの段で、2つの問いを別々に答えられる。

## B. 次にいつ出すか（アルゴリズム）

| 案                                    | 中身                                                                                                                                                               | 手間                                                                                      | 期待できること                                                                                                           | 注意                                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| **A1: いまの SM-2 のまま**            | 現状維持（必要なら細かい調整だけ）                                                                                                                                 | なし                                                                                      | 変化なし・安全                                                                                                           | 精度は上がらない                                                                                              |
| **A2: FSRS に乗り換える（既定の値）** | Anki も採用している FSRS（無料・MIT ライセンス。TypeScript 版 `ts-fsrs`、FSRS v6）。語ごとに **難しさ・安定度・思い出せる確率** を持ち、「90% まで落ちた頃」に出す | DB に列を足す（安定度・難しさ・最後の復習日）。今の語は ease と間隔から初期値を作って移す | 約1万人・約7億件の復習で作られた既定値。公開の比較で SM-2 より予測が正確。第三者の試算では同じ定着で復習が 2〜3 割少ない | 本番の DB 変更なのでオーナーの承認が要る。採点 1〜5 を FSRS の4段（もう一度／難しい／普通／簡単）へ対応づける |

## 決めたこと（2026-10-02 実装済み）

オーナーの選択: **状態の分け方は S1（いまの 6 段、% で決める）のまま、復習の仕組みは A2（FSRS、既定の値）**。
「写真を撮ったときはまだ覚えてないから 0% になるように」「復習を何回もして何回も正解することによってグラフの角度が変わるようにしたい」「長期記憶でも一度間違えたら傾きがまた少し急になって復習の頻度が増える」。

| 決めたこと   | 中身                                                                                                                                                                                                                                                                                                           | 場所                                                    |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 式           | FSRS-6（MIT の `ts-fsrs` をそのまま使う。既定の重み 21 個）。語ごとに **D（難しさ）・S（安定度）・R（いま思い出せる確率）**                                                                                                                                                                                    | `src/lib/srs.ts`                                        |
| DB           | **列は増やさない。** `interval_days`（整数）= S（日。狙い 90% で出すと FSRS の間隔は S そのものなので、「次に出すまでの日数」と同じ数。0 = 未復習）。`ease` 1.3〜3.0 ↔ D 10〜1 の一次の対応。`repetitions` = 連続正解数。`last_reviewed_at` = 記憶の起点。既存の値はそのまま読める（出題日の値は変わらず 90%） | `srs.ts` の冒頭の表                                     |
| 採点 → 評価  | 3 未満 Again、3・4 Hard、5 Good。Easy は使わない（4 択で速く当てても「簡単」の証拠にならない）                                                                                                                                                                                                                 | `ratingOf`                                              |
| 狙う定着率   | **90%**（今までどおり）。出題日 = S の日                                                                                                                                                                                                                                                                       | `TARGET_RETENTION`                                      |
| 撮った直後   | **0%**・「忘れかけ」。最初の復習で記憶が始まる（Good 2 日・Hard 1 日・Again 1 日）                                                                                                                                                                                                                             | `retentionNow`（起点が無い／S が 0 なら 0）             |
| 曲線         | 指数 → FSRS のべき関数 `R = (1 + 0.98·t/S)^−0.1542`。出題日は 90% で同じ、遅れた語は少し高く出る（例: 2 倍遅れで 81% → 85%）                                                                                                                                                                                   | `forgettingCurve` / `daysUntilRetention`                |
| 間違えたとき | S が縮む（S を超えない）。間隔 90 日の語は 4 日ほど、若い語は 1 日で戻る。D も上がる（以後の伸びが鈍る）                                                                                                                                                                                                       | `nextSrs`                                               |
| Jev          | 影の運用のまま。採点後に Jev の日数を記録するだけ。live のときの柵は FSRS の日数を基準にする                                                                                                                                                                                                                   | `reviews.functions.ts` の `gradeReview`、`pickInterval` |
| 画面         | 見出しの「0 / 10」と「あと N 語」の数は出さない。全体のグラフは線 1 色＋記憶の段の帯（明暗のトークン）                                                                                                                                                                                                         | `ReviewHeader` / `MiniRetentionGraph` / `.mem-band`     |

**今後の候補:** A3（人ごとの最適化）は復習の記録（`review_history`）が十分に貯まってから。A4（Jev）は影の記録で FSRS より当たると示せてから。
