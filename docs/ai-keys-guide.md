# AI の鍵の入れ方と、アプリの中での切り替え方（初心者向け）

（オーナーの質問 2026-09-28「使う AI の切り替え画面、複雑すぎる。openrouter の使い方分からないし、
今はそれぞれの AI を直接 api を取得し、lovable に貼り付けてる。どのように設定すればいいの？
lovable のシークレットに貼り付けて、アプリ内の AI 設定で使うモデルを変更できるの？」）

## 答え（先に）

**はい、できます。今のやり方（各社の鍵を Lovable の Secrets に入れる）のままで大丈夫です。**
OpenRouter は使わなくても困りません。鍵を入れたら、アプリの設定 → 開発者の欄
「AI の切り替え」で、機能ごとに **「会社」→「モデル」** を選んで「適用」を押すだけです。

## 用語

| 言葉                    | 意味                                                                                                |
| ----------------------- | --------------------------------------------------------------------------------------------------- |
| API キー（鍵）          | その会社の AI を使うための合言葉。これを持っている人の分として料金がかかる。**人に見せない**        |
| Secrets（シークレット） | Lovable の中の、鍵をしまう金庫。サーバだけが読めて、画面（利用者の端末）には出ない                  |
| モデル                  | 同じ会社の中の AI の種類。⚡速い・安い物と、🧠賢い物がある                                          |
| OpenRouter              | 1つの鍵で色々な会社の AI を呼べる仲介サービス。**使わなくてよい**（色々な会社を試したい時だけ便利） |

## 手順（行動プラン）

### ステップ1: 鍵を Secrets に入れる（1社につき1回）

1. 使いたい会社の管理画面で API キーを作る。
2. Lovable でこのプロジェクトを開く → **Cloud → Secrets** →「追加」。
3. **名前は下の表のとおりに**（1文字でも違うとアプリが見つけられない）。値に鍵を貼る。
   **チャットには貼らない**（Secrets の入力欄にだけ）。

| 会社                       | Secrets の名前       |
| -------------------------- | -------------------- |
| Google Gemini              | `GEMINI_API_KEY`     |
| OpenAI（ChatGPT）          | `OPENAI_API_KEY`     |
| Anthropic（Claude）        | `ANTHROPIC_API_KEY`  |
| DeepSeek                   | `DEEPSEEK_API_KEY`   |
| Kimi（Moonshot）           | `MOONSHOT_API_KEY`   |
| OpenRouter（使う場合だけ） | `OPENROUTER_API_KEY` |

### ステップ2: アプリで選ぶ

1. アプリの **設定** → 下の方の開発者の欄 → **「AI の設定（開発者）」** を開く（iOS の開発者画面も同じ設定）。
2. 一番上が緑（動いています）か確かめる。赤なら、鍵が1つも見つかっていない。
3. 「機能ごとの AI」で、機能ごとに1つ選ぶ:
   - **自動（最新 Gemini Flash / Flash-Lite）**: 既定。スキャンは最新の Flash-Lite、ほかは最新の Flash。
   - **会社の下のモデル**: 鍵を入れた会社だけ並ぶ（入れていない会社は「鍵が未設定」で押せない）。
     スキャンは写真を読めるモデルだけ。
4. 選んだ瞬間に保存される。30秒以内に全員のアプリに効く。「いま: …」に実際に使うモデルが出る。
5. 元に戻したい時は「自動」を選ぶ。

### 困った時

- 会社が選べない → Secrets の名前が表と違う。名前を直す（値はそのまま）。
- 「モデル一覧を読めませんでした」→ 鍵が間違っている・期限切れ・その会社の支払いが止まっている。
- 選んだ AI が失敗しても、アプリは止まらず、いつもの AI に自動で戻る（2026-07 の障害の後に入れた安全柵）。

## 画面が簡単になった理由（2026-09-28 の変更）

- 前は OpenRouter の数百のモデルから選ぶ画面だった → **鍵を入れた会社のモデルだけ**に絞った。
- モデルの名前を手で打つ欄（「詳しい設定」）は 2026-10-09 に消した。機能ごとに「自動（最新の Gemini）」か、鍵のある会社のモデルを一覧から選ぶ（`docs/admin-ai-api.md`）。
