## 日記

正: `src/routes/_authenticated/journal.tsx` + `src/lib/journal-drafts.ts`（試験8件）

その日の写真・場所・時間から、AI が学習言語で振り返り日記を作ります。
利用者が直せます。ホームの見開きから**その場でページをめくって**書けます。

### ⚠️ 下書きが消える危険

> この画面には「保存」が無く、文章が DB に入るのは**添削が成功した後だけ**。
> 添削には1日の上限があるので、**上限に達した日は保存に到達する道が1本も無い**。
> つまり**端末の控えが唯一の置き場所**で、ここが狂うと書いた文章が消える。

だから:
- 下書きの鍵は**日付で分ける**（「昨日の文章で今日を上書き」を防ぐ）
- ⚠️ ただしそれだけだと、**サーバーに届かなかった文章が日付をまたいだ瞬間に
  手の届かない所へ行く**。だから日をまたいだ書きかけを拾い直して見せる
- 今日以降の鍵は触らない（いま書いている物）

**iPhone 版でも「端末の控えが唯一の置き場所」である事実は変わりません。**
`UserDefaults` かファイルに、同じ日付鍵で置くこと。

### 足場（白紙で書かせない）

`src/lib/scaffold-cache.ts`。場所・時間・タグ付けした人から、
書き出しの候補を出します。

## 単語帳

正: `src/routes/_authenticated/wordbooks.tsx` + `src/lib/wordbook.ts`（試験14件）

紙の単語帳を撮ると、そこにある語のカードを**一括で作れます**。

### ⚠️ 図鑑に混ぜない

> 図鑑は「街で出会って**自分で撮った**物」の記録という約束で作ってある。
> 単語帳の語には写真も場所も無いので、混ぜると図鑑の意味が変わり、
> **絵の無い札が並ぶ**。

復習側の**本棚**として別に持ちます。復習も「図鑑の語」と「単語帳の語」で分かれます。

## 設定

正: `src/routes/_authenticated/settings.tsx`（1,541行）

主な項目:

| 項目 | 保存先 | 備考 |
|---|---|---|
| 表示言語（日/英/繁中） | サーバー＋端末 | |
| 学習言語（台湾華語/英語） | サーバー | |
| 母語 | サーバー | 発音のコツ・覚え方に効く |
| 到達目標の級 | サーバー | 生成する語彙の難度に効く |
| 読みの表記（注音/拼音・米/英IPA） | 端末 | |
| 復習モード（自動/話す/4択） | 端末 | ⚠️ **絵文字を付けない**（2026-08-28 ⑥） |
| 表示画像の種類 | 端末 | |
| キャッチの速さ（詳細/速い） | 端末 | ⚠️ **既定を変えない** |
| テーマ（6種） | 端末 | |
| 音・触覚 | 端末 | |
| 場所の通知 | 端末＋権限 | |
| **機能ごとに使う AI** | サーバー（`app_config`） | 管理者のみ |

### ⚠️ 端末ごとの設定と、サーバーの設定を混ぜない

読みの表記・写真の種類・キャッチの速さは**その端末の上で起きること**なので端末に持ちます。
学習言語・母語・級は**その人の持ち物**なのでサーバーに持ちます。

iPhone 版でもこの線を守ること。混ぜると「iPhone で変えたら Web も変わった／変わらない」が
予測できなくなります。

### 機能ごとの AI 切替

`getAiModelConfig` / `setAiModelConfig`（`src/lib/admin.functions.ts`）。
**既に完成しています。** 5つの機能（scan / card / review / journal / audit）に
それぞれ `provider:model` を指定できます。

## ソーシャル — **いまは無効**

正: `src/lib/features.ts` の `SOCIAL_ENABLED = false`

対象: feed / discover / notifications / post/$postId / u/$userId の5画面。

> ここに並ぶのは「作りかけだから隠す」ものではなく、**出すと嘘になるから隠す**ものだけ。

理由（そのまま引用に値します）:

- 5画面は互いにリンクし合っているだけで、**アプリのどこからも辿り着けない**（下タブにも無い）
- `createPost` に呼び出し元が1つも無いので、**誰も投稿できない**
- つまり URL を直接打った人だけが、**永久に空のタイムライン**に行き着く
- さらに**通報・ブロック・モデレーションが1つも無い**。
  他人の投稿が並ぶ画面をその状態で開けておくのは、単に未完成なのではなく**危ない**

⚠️ **iPhone 版でも、この5画面は作らないこと。**
出すと決めたときに、通報・ブロック・利用規約への同意を**まとめて作ってから**。
