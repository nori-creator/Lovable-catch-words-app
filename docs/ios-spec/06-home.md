## 構成

```
本棚（今日の進み具合・連続日数）
  ↓
今日の見開きアルバム（撮った写真を台紙に貼る）
  ↓
この日の日記
  ↓
過去の日（下へ続く）
```

---

## アルバム

### 台紙は本物っぽく

`.album-page` が紙の繊維と周辺減光を持ちます。背景は4種類から選べます
（`paper` / `frame` / `notebook` / `cork`、端末ごとの設定）。

### 写真の貼り方

- 写真のある札 … **印画紙**（白フチ＋三角コーナー＋ツヤ）
- 写真の無い札 … ⚠️ **台紙に文字だけ**

⚠️ **これはオーナーが2回指摘した所です**（2026-08-27 ②／2026-08-28）。
文字入力で拾った語には写真が来ないのに印画紙を被せていたので、
**白い紙を1枚貼って、その上に語を書いた**絵になっていました。

いまは `.album-note` から**地も縁も下罫も全部外して**、台紙に字だけが載ります。
貼っていない物は、貼っていないように出す。

### 束ね方（日 / 週 / 月）

正: `src/lib/album-span.ts`（試験20件）

⚠️ **3ヶ月遡ると90ページ**になります。オーナーがメモに5回書いた
「昔に撮ったもの見ない」「下にスクロールするモチベーションない」はここに直接効きます。
週や月でまとめれば、同じ量が12ページ・3ページ。

- ⚠️ **週の始まりは月曜**（台湾も日本も）
- ⚠️ **ISO の週番号（`2026-W34`）は使わない** — 年をまたぐ週で番号が飛ぶ規則が入り、
  見出しに出す文字列として誰も読めない。代わりに**その週の月曜の日付**を鍵にする
- ⚠️ **地方時で数える**。UTC で数えると日付が1日ずれます

### 長押し

札を長押しすると、その札の**主役の写真**を選べます（元写真 / 切り抜き / 自撮り）。
⚠️ **アルバムでの選択がいちばん強い**（オーナー指示 2026-08-25
「アルバムと単語詳細で別々に種類を選べる」）。

優先順位（`src/lib/photo-surface.ts`、試験12件）:
```
この端末に憶えてある物 → 札の共通の選択(hero_role) → 設定 → 画面の意図
```

⚠️ **ネットの絵はアルバムに貼りません。**
アルバムは自分が出会って撮った物の記録で、借りてきた絵を同じ紙に貼ると
**撮った日の思い出と見分けが付かなくなる**からです。
ネットの絵は「単語の詳細の見出し」という置き場所を別に持っています。

## 本棚

正: `src/lib/shelf-plan.ts`（試験12件）/ `src/lib/book-spine.ts`（試験23件）

集めた語がジャンルごとの**背表紙**として並びます。
⚠️ 54個×3列の配置で、背表紙の文字は縦組み。絵文字も1文字として扱います。

---

## 読み込み中と空のとき

⚠️ **起動するたびに必ず通る面**なのに、以前はルートの三項の中に直書きで、
**一度も絵に撮られていませんでした**（`HomeLoading`）。

⚠️ 読み込み中の台紙の高さは**実物のアルバムとほぼ同じ**にすること。
低い物を置くと、読み終わった瞬間に下の「過去の日」が突き落とされます。

---

## 預かり中の写真の帯

オフラインで撮った写真がある時に出ます。
⚠️ **描く所だけを部品に切り出してあります**（IndexedDB を触る側のままでは
検査のハーネスから描けず、**オフラインでしか出ないこの帯が一度も機械に見られていなかった**）。

iPhone 版でも同じ分け方を守ること。

---

## 日記への入口

⚠️ `onWrite` を渡すと**その場でページをめくります**
（オーナー指摘: アルバムの写真と日記が別の機能に分離していた）。
渡さない場所では今までどおり日記の画面へのリンク — **過去の日記を読む道を塞がない**。

## 確認項目

- [ ] 写真の無い札が**台紙に文字だけ**（印画紙も罫も無い）
- [ ] 写真のある札は印画紙とコーナーを保つ
- [ ] 日/週/月を切り替えられ、週が**月曜始まり**
- [ ] 日付が地方時でずれない
- [ ] 長押しで主役の写真を選べ、その選択が**アルバムだけに効く**
- [ ] ネットの絵がアルバムに貼られない
- [ ] 読み込み中の台紙の高さが実物とほぼ同じ（読み終わりで飛び跳ねない）
- [ ] オフラインの預かり帯が出る
