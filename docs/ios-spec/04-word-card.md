## いちばん大事な規則

> **描く条件と数える条件を必ず一致させる。**

節を出すかどうかは `sectionHasContent()`（`src/lib/card-sections.ts:165`）**1箇所**で決めます。
理由:

- 画面は「この節は空か」を知って、空なら**見出しごと出さない**
- サーバーは「この節はまだ空か」を知って、空なら**作りに行く**

同じ問いに2つの答えがあると、**サーバーが「空だ」と言い続けて作り直し、
画面は「埋まっている」と言い続ける — 止まらない生成**になります。

⚠️ **このアプリは実際に3回壊しています**（`usage_chunks` / `usage_context` / `example`）。
毎回「見出しだけの空の節」が出ました。

### iPhone 版での対応

**`/api/v1/word/:id/card` が「出す節の一覧と、その中身」を返す。**
Swift 側は返ってきた順に並べるだけ。判定を Swift に書き写さないこと。

## 節ごとの規則

### 1. 意味
`meaning_ja` があれば出す。

### 2. ネットの画像
⚠️ **行の中身では決められない**（取りに行ってみないと分からない）。
1枚も見つからなければ**節ごと出さない**。判定は画面側
（`src/lib/use-web-images.ts` と `WordCard` の `canShow`）。

出所は3つ。**鍵の要らない出所を必ず1つ持つこと**:

| 出所 | 鍵 |
|---|---|
| Wikimedia Commons | **不要** |
| Unsplash | `UNSPLASH_ACCESS_KEY` |
| AI 生成 | `LOVABLE_API_KEY`＋残高 |

⚠️ 以前は上2つが無く**鍵か残高を要る出所しか無かった**ので、
切れると「画像がありません」だけが残っていました（オーナー報告 ④）。

### 3. 頻度・使う場面
中身は3つ: 頻度メーター / 口語⇄書面メーター / **場面の札**。

**場面の札**（`src/lib/scene-bubbles.ts`、試験24件）:

- 軸ごとに束ね、束に見出しを付ける
  — ここだけ / どこで / いつ / どんな場面で / どんな物か / どんな気持ちで
- 総数の上限8、1軸の上限4
- **札が1つも作れなかったときだけ**文章に落ちる

⚠️ **「限定」は理由が無ければ出しません。**
`region_scope` に地名があるだけでは不足で、`region_scope_kind` に
`specialty` / `institution` / `regional_word` のどれかが要ります。

> 本番データで数えたら、`region_scope` の入った9語のうち**6語が誤り**でした
> （扇風機・エアコン・シュークリーム・エッグタルト・棒 が全部「台湾限定」）。

季節限定は「**4ヶ月以内で3分の2以上が1つの季節に寄る**」。
文旦の 8〜10月は秋として拾い、扇風機の 5〜9月は季節の話にしません。

**浮遊感の出し方**（オーナー指示 2026-08-28 ①）:
位置は**整列**させ、浮遊感は影の3段の奥行き・ゆっくりした上下（2〜4px）・
押した時の弾みで出す。⚠️ **位置そのものを物理で飛ばさないこと**（並びが毎回変わる）。
値は札の名前から決めるので、描き直してもちらつきません（`src/lib/bubble-float.ts`）。

iPhone 版: `withAnimation(.easeInOut.repeatForever())` の上下 +
`shadow(radius:)` の3段 + `UIImpactFeedbackGenerator` の弾み。

### 4. 例文
⚠️ **学習言語で書かれていない文は「無い」扱い**（`looksLikeTargetLanguage`）。

> 学習言語の写しが既定へ戻る隙間に作られたカードには、
> **英語の語を中国語の文へ埋めた例文**が入っていた。
> 画面は落としていたが数える側は落としていなかったので、見出しだけの節が残った（3度目）。

- 語を**青いマーカー**で色付け（`src/lib/mark-term.ts`）
- 沈めた面に置き、行送り1.85・行長34em（読みやすさのため）
- ⚠️ **左の青い罫は引かない**（2026-08-28 ④ で削除）
- 発音ボタン付き

### 5. 追加の例文
2つ。各文に「いつ・どんな気持ちで言うか」の場面が付きます。

### 6. 使い方チャンク ← **規則がいちばん多い**

正: `src/lib/extras.ts` の `refineUsageChunks`（試験42件）+
`src/lib/generic-chunks.ts`（試験15件）

**落とすものが6つ**:

| # | 落とすもの | なぜ |
|---|---|---|
| 0 | **どの名詞にも付く汎用の組み合わせ** | 「買{語}」「喜歡{語}」はその語について何も教えていない |
| 1 | **量詞に触れる型** | 量詞の欄が別に在る。**触れた時点で重なっている** |
| 2 | 長すぎる型 | 8文字（英語は4語）を超えると型ではなく例文 |
| 3 | 文になっている型 | 句点・感嘆符・疑問符が入っている |
| 4 | 見出し語しか無い型 | 情報が0 |
| 5 | 同じ文字列の重複 | |

そのうえで**先頭5つ**に切ります（生成側が頻度順に並べるので後ろから）。

⚠️ **汎用語の表は短く保つこと。** 一度 帶/用/拿 まで入れたら
既存の試験が「帶雨傘」を落として捕まえました。一見どこにでも付きそうで
実は相手が決まっている動詞が多い。買う・売る・持つ・欲しい・好き の族だけ。

⚠️ **骨組み（我・的・了）しか残らない型は落とさない。**
「了」の位置こそがその型の教える中身で、機械的に落とすと文法の型が全部消えます。

⚠️ **英語は文字数ではなく語数で測る。** 8文字の物差しを英語に当てたら
`put on socks` も `a pair of socks` も**1つ残らず落ち**、
「生成されていない → 作り直す → また落とす」が延々と続いていました
（待ち時間もお金も払いながら画面には一度も出ない）。

**見た目**: 札1つずつが押せて、それぞれ独立して鳴る。行の右端にも通しの発音ボタン。
札は 44px 以上（`min-h-11 min-w-11`）。

### 7. 量詞（台湾華語のみ）
名詞のときだけ。⚠️ **説明は中国語で書かない**（中国語なのは語と読みだけ）。

### 7'. 活用 / 数え方と冠詞 / 句動詞 / 強く読む所（英語のみ）

- **活用**: ⚠️ `forms` が在るだけでは足りない。不変化名詞は全欄が空になるので、
  実際に値のある欄が1つ以上あるときだけ。`lemma` は原形なので数えない
- **強く読む所**: 音節に切れていなければ節にしない（`note` だけでは不可）
- ⚠️ 活用は **ECDICT から入る辞書の事実**で、AI に作らせない
  （作らせると "child" の複数形が "childs" になり得る）

### 8. 類義語・反義語・関連語
⚠️ 見出しは「にてる言葉・関連語」ではなく **「類義語・反義語・関連語」**
（2026-08-27 ⑧ で中の札に合わせた）。

- 各語に**読み**（注音/IPA）を付ける。⚠️ **読みを空にしない** — 読めない語を並べても覚えられない
- 語そのものは `text-body`（一段大きく）、説明は小さく薄いまま
- 各行に発音ボタン

### 9. 発音のコツ
その人の**母語**でつまずく所に絞る（`src/lib/l1.ts`、684行・試験28件）。
日本語話者なら声調・有気音・そり舌。中国語話者が英語を学ぶなら冠詞・語末子音・l/r。

### 10. 語源・部首（英語では「語源」）

### 11. 覚え方
`src/lib/mnemonic-rule.ts`。母語の既知語から橋を架ける
（「ドッヂボール」→ dodge、「巧克力」→ chocolate）。

### 12. 台湾メモ / 文化の一言

### 13. 実際の使われ方
決まった数の外部リンク（YouGlish・教育部辞典・Dcard など）。
⚠️ **いつでも描ける**ので `sectionHasContent` は常に true。

### 級の出し方（2026-08-27 ⑭）

正: `src/lib/level-source.ts`（試験8件）+ `src/lib/level-scale.ts`（試験43件）

⚠️ **検定に無い語に級を付けないこと。** 以前は指示文が6つのどれかを選ばせていて、
「この語は検定に無い」と答える口がありませんでした。

優先順位:
```
辞書に在り級も分かる → その級
辞書に在るが級が無い → 級外（dictionary-out）
辞書に無い          → AI の判断 → それも無ければ不明
```

⚠️ **`dictStep === undefined`（辞書に無い）と `null`（辞書に在るが級が無い）を混同しない。**

級外の語には級の代わりに**その語が出る検定の印**を出します
（`src/lib/exam-tags.ts`、最大4つ）。

段の形は TOCFL 1〜6 / CEFR A1〜C2 のどちらも「6段＋3帯」なので、
`TocflLadder` が**両方に使えます**。
