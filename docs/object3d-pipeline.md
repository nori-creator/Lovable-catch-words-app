## 1. 用語（はじめての人向け）

| 言葉           | 意味                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| 3D モデル      | 前後左右から見られる立体のデータ。ここでは **GLB**（1つのファイルに形・色・質感をまとめた形式）を使う |
| Tripo3D        | 写真1枚から 3D モデルを作る外部の AI サービス（有料・1回ごとに課金）                                  |
| Blender        | 無料の 3D 制作ソフト。ここでは「Python の部品（bpy）」として、画面を開かずに命令だけで動かす          |
| 面（ポリゴン） | 3D の形を作る小さな三角形。多いほど細かいが、スマホで回すと重くなる                                   |
| Draco          | 3D の形を小さく縮める方式。三角形の数は同じまま、ファイルの大きさを 1/4〜1/6 にできる                 |
| three.js       | ブラウザで 3D を描く道具。アプリの中で 3D を回して見せる所に使っている                                |

## 2. 全体の流れ

参考にしたのは、オーナーが添付した GitHub の **Camera to 3D**（ahujasid、MIT ライセンス）です。
その流れにアプリ用の仕上げ（⑤）を足しました。

```
① 撮る（アプリのカメラ）
② 背景を抜く（Gemini）……………… 物だけを切り抜く。3D の出来がここで決まる
③ 粗い形（Tripo v3.0、色なし）…… 10〜20秒。まず「組み上がっていく」演出を始める
④ 仕上げの形（Tripo v3.1、色と質感）… 1〜2分。できたら差し替える
⑤ Blender で整える（このリポジトリの scripts/blender/object3d_clean.py）
   ・部品を1つにまとめる　・面を 12,000 まで減らす　・下の真ん中を原点に
   ・大きさを揃える　・なめらかな陰影　・Draco で縮めて GLB に書き出す
⑥ 保存（Supabase Storage。その人だけが読める場所）
⑦ 図鑑で 360 度回して見る（three.js、src/components/three/object-viewer.ts）
```

### Blender の仕上げを試す手順

1. Blender を Python の部品として入れる: `pip install bpy==4.5.*`
2. 見本を作る: `python scripts/blender/object3d_clean.py --demo 出力.glb --no-draco`
3. Tripo の GLB を整える: `python scripts/blender/object3d_clean.py 入力.glb 出力.glb --faces 12000`
4. 確認用ページで見る: 出力を配って `?scene=object-3d&step=ready&glb=<URL>` を開く

## 4. 本番にするときに決めること・作ること

1. **⑤ をどこで動かすか。** Supabase の Edge Function では Blender を動かせない（重すぎる）。
   候補は「保存の直後に仕事の箱（キュー）に入れ、Blender の入った小さなサーバで順に処理」
   （例: Cloud Run や Fly.io の 1 台）。**⑤ を省き、Tripo の出力をそのまま使う**のも可能
   （重さ・向きのずれを three.js 側で吸収する。品質は少し落ちる）。
2. **Draco の読み込み**: three.js の `DRACOLoader` と、その解読ファイルをアプリに同梱する
   （外部の CDN は使わない）。
3. **Pro の判定と上限**: 1日○回まで、失敗は回数に数えない、など。
4. **費用の見積もり**: Tripo は 1 回ごとに課金。粗い形と仕上げの2回分かかる。
   → 公式の料金表で確定させてから上限を決める（ここでは数字を推測しない）。
5. **プライバシー**: 撮った写真は外部（Gemini・Tripo）に送られる。利用規約・プライバシー
   ポリシーに書き、初回に同意を取る。

## 5. リスク

- 形の出来は写真次第。暗い・物が小さい・背景がごちゃごちゃだと崩れる（② が要）。
- 透明な物（コップ）や細い物（ストロー）は苦手。
- 1回あたりの費用と待ち時間（1〜2分）がかかる。待つ間の演出（組み上がる点）で体感を短くする。
