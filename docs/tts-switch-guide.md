# 発音の声（音声 AI）を切り替える手順（初心者向け）

最終確認: 2026-09-27

## 何ができるか

単語・例文の発音を、どの会社の音声 AI で作るかを**アプリの設定画面から**切り替えられます（開発者＝オーナーのアカウントにだけ表示）。

選べる会社（2026-09-27 時点）:

| 会社 | 状態 | 鍵の名前（Secrets） |
|---|---|---|
| Azure AI Speech（Microsoft） | 使える。台湾華語専用の声あり | `AZURE_SPEECH_KEY` と `AZURE_SPEECH_REGION` |
| ElevenLabs | 使える | `ELEVENLABS_API_KEY` |
| MiniMax | 使える | `MINIMAX_API_KEY` |
| VoAI / ATEN | **未接続**（公式の API 仕様を入手できていない） | — |

何も選ばなければ「これまでの声（既定）」で鳴ります。

## 言葉の説明

| 言葉 | 意味 |
|---|---|
| 音声 AI（TTS） | 文字を読み上げて音にする AI |
| 鍵（API キー） | その会社のサービスを使うための合言葉。他人に見せない |
| Secrets | Lovable Cloud の、サーバだけが読める設定の置き場 |
| リージョン | Azure のサーバの場所。例 `japaneast`、`eastasia` |

## 手順（Azure に切り替える例）

1. **Azure で音声サービスを作る。**
   - Azure ポータルで「Speech（音声）」のリソースを作成します。
   - 公式手順: https://learn.microsoft.com/azure/ai-services/speech-service/get-started-text-to-speech
2. **鍵とリージョンを写す。** 作ったリソースの「キーとエンドポイント」画面に、キー（2つあるうちのどちらか）とリージョン（場所）が出ます。
3. **Lovable に入れる。** プロジェクト → Cloud → Secrets に次の2つを追加します。
   - `AZURE_SPEECH_KEY` = 手順2のキー
   - `AZURE_SPEECH_REGION` = 手順2のリージョン（例 `eastasia`）
4. **アプリで選ぶ。** アプリの 設定 →「開発者専用」→「発音の声を切り替える」を開きます。
   - 言語（台湾華語 / 英語）ごとに「会社」を Azure にする。
   - 「声の ID」は候補から選ぶ（台湾華語なら `zh-TW-HsiaoChenNeural` など）。
   - 「試しに鳴らす」で聞いて、かかった時間も確かめる。
5. 鍵が足りないときは、画面に「鍵が未設定です: …」と出ます。その名前を Secrets に入れてください。

## 速さについて（速さ最優先の設定）

- **2回目以降は速い:** 一度作った音は保存され、次からは作らずにそのまま鳴ります（会社によらず同じ）。
- **1回目が遅い:** その場で作るので、会社とモデルの速さが効きます。
  - ElevenLabs は「モデル」を `eleven_flash_v2_5`（既定）にすると速さ優先。ElevenLabs 公式が低遅延のモデルとして案内しています: https://elevenlabs.io/docs/models
  - 「試しに鳴らす」に出る**かかった時間**で、実際に比べてください。ネットの評判より、この数字のほうが当てになります。
- **この回の改善:** 1回目に作った音を、保存が済んだらそのまま端末に渡すようにしました。前は「保存 → URL を作る → 端末がもう一度落とす」を待っていたので、その分速くなります。
- 声を切り替えると、**前の声で保存した音は使われません**（新しい声で作り直す）。切り替えた直後の1回目は、どの語も遅くなります。

## 注意（リスク）

- 会社ごとに**料金**がかかります。料金表は各社の公式ページで確認してください。
- 鍵を他人に見せない・チャットに貼らないでください（Secrets にだけ入れる）。
- VoAI と ATEN は、公式の API 仕様を受け取るまで接続しません（推測で繋ぐと鳴らない・違う声が貯まる危険があるため）。
