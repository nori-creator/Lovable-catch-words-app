# 12. UX心理設計とテーマ戦略 (2026-07-27)

過去のデザイン指示は一旦忘れ、「なぜ人はアプリを毎日開くのか」から組み直した。
結論を先に書く。

> **ホーム画面をアルバムにするのは正解。ただし「アルバム」ではなく
> 「自分が作った作品のギャラリー」として見せる必要がある。**

---

## 1. 世界の定着しているアプリが共通して持つ3つの心理装置

調べたのは Instagram / TikTok / YouTube(視覚的インパクト)、BeReal / Locket
(思い出・親密さ)、Pokédex 系収集ゲーム(収集・自慢)、Apple 純正アプリ
(写真・Fitness / ミニマルと上質感)。一つを真似るのではなく、**継続の裏で
効いている無意識の仕組み**だけを抜き出した。

### ① 自分の痕跡が増えていく (Endowed progress / IKEA効果)

自分が手を動かして作ったものは、価値を過大評価する。写真アプリを消せない
のは「機能」ではなく「自分の履歴」があるから。
→ **本アプリの最大の資産は「ユーザー自身が撮った写真」**。UIはこれを主役に
し、装飾は限界まで引く。

### ② 一目で「整っている」と分かる快感 (Processing fluency)

人は情報が少ない労力で処理できたとき、それを「美しい」と感じる。Apple の箱、
高級時計のケース、カードアルバムの共通点は **同じ形が規則的に並ぶこと**。
→ 崩したコラージュより、**規則的なグリッド + 一定の余白**が「所有したくなる」。
(今のランダム回転のスクラップブックは "かわいい" が "上質" ではない。)

### ③ 予測できるが少しだけ揺れる報酬 (Variable reward)

毎回同じ演出は3日で飽き、毎回違いすぎると不安になる。
→ **キャッチ演出の骨格は固定・声だけランダム**。この実装が今回入れた
決め台詞ボイス(10種+開発者が追加可)。

### ④ 待ち時間を報酬に変える (Labor illusion)

「AIが2秒考えている」ことを隠すと不信になり、見せると価値が上がる
(実験: 進捗を可視化した検索は、同じ速度でも結果の質が高いと評価される)。
→ スキャン中に **走査線・解析グリッド・段階ラベル**を出す。
「少しだけ待ってね」のような**待たせる言葉は出さない** — 代わりに
「いま何をしているか」を出す。

## 2. ホーム画面: アルバムは正解、ただし方向を変える

### やらないこと(NORI指定と心理の両方から)

- ストリーク・ミッション・バッジの羅列 → 外発的動機は3日で飽き、
  途切れた瞬間に離脱する(ストリーク破綻の離脱率は既知の問題)
- チープなアイコン、ゲーム風の装飾、ボタンが多くて視線が迷う画面

### やること

1. **写真を大きく、規則的に**。1日1ページ、同じ比率のタイルが整列。
   「今日の1枚」だけ大きく見せる非対称は許容(視線の入口を作る)。
2. **日付は主役ではない**。細い書体で小さく、写真の邪魔をしない。
3. **サムネイルのインパクト**: Instagram / TikTok と同じで、
   人は「良い写真」に指を止める。切り抜きより **実写のまま**が強い。
4. **数字は1つだけ**。「◯枚の思い出」以外の数字は出さない。
5. **スクロールが履歴を遡る体験**そのものになる(過去ページへ連続)。

現行実装は「印画紙 + 三角コーナー」の物質感を採用済み。次の段は
テーマ切替で **Museum White(白壁・作品主役)** と
**Collection Premium(紺×シャンパンゴールド・所有感)** を比較できる。

---

## 3. 配色: 今の深い青は残す。比較用に10案

`data-ui-theme` で CSS 変数だけを差し替える方式にした
(コンポーネントは一切変更しない = **現行デザインは絶対に壊れない**)。

| テーマ                | 心理的な狙い                          |
| --------------------- | ------------------------------------- |
| **現行 (Apple Blue)** | 信頼・清潔。**常に残す基準線**        |
| Collection Premium    | 紺×金。高級時計のケースを開ける所有感 |
| Museum White          | 白壁。作品(写真)が主役、UIは消える    |
| Titanium              | 冷たい金属。道具としての精度感        |
| Darkroom              | 暗室の赤灯。現像=記憶の定着の比喩     |
| Washi                 | 和紙と墨。台湾の紙の看板と地続き      |
| Night Market          | 夜市のネオン。学びの舞台そのもの      |
| Linen                 | 麻と若草。長時間でも目が疲れない      |
| Ink                   | 純黒。写真のコントラストが最大        |
| Atelier               | 生成りと赤茶。手作業の温度            |
| Aurora                | 藍→紫。AIの知性を色で表す             |

**フォント**: 全テーマで英数=Inter / 日本語=Noto Sans JP / 繁体字=Noto Sans TC
を維持し、見出しだけ `--font-display`(Instrument Serif)。
書体をテーマごとに変えると一貫性が壊れるので、**字体は固定**が正解。

## 4. スキャン: 「現実世界をAIが読んでいる」を演出する

Capwords 的な体験の核は **世界に重ねて情報が現れること**。
実装した5層(すべてCSS/SVG、外部アセットなし):

1. 走査線 — 上から下へ一度抜ける光の刃(いま読んでいる場所)
2. 解析グリッド — 極薄の格子が呼吸する(空間を測っている)
3. コーナーブラケット — 照準が締まる(対象を捕まえた)
4. 粒子の上昇 — 読み取った情報が吸い上げられる
5. 段階ラベル — 「空間を捉える → 文字と物を読む → 台湾華語と照合」

**カメラは全画面**。小さな窓では「世界をスキャンしている」感覚は出ない。

## 5. マイクロインタラクションの原則(全画面共通)

| 場面       | 挙動                                           | 根拠                     |
| ---------- | ---------------------------------------------- | ------------------------ |
| ボタン押下 | `active:scale-95` で沈む。**押した瞬間**に反応 | 因果の即時性             |
| 画面遷移   | 200-300ms のフェード + わずかな上方向          | 位置関係の維持           |
| 成功       | 音 + 触覚 + 視覚を**同時**に                   | 多感覚一致で記憶に残る   |
| 待機       | 進捗が動く。スピナーだけにしない               | Labor illusion           |
| 破壊的操作 | 2段階(削除は「もう一度タップ」)                | 誤操作の恐怖を消す       |
| 減速指定時 | 移動を消し、音と触覚だけ残す                   | `prefers-reduced-motion` |

---

## 6. 次に検証すること(仮説→計測)

1. **ホームのグリッド規則性** — ランダム回転 vs 整列。7日継続率で比較
2. **テーマ** — Museum White / Collection Premium / 現行の3本で
   「1日の起動回数」を比較
3. **決め台詞ボイス** — ON/OFF でキャッチ回数を比較(飽きが来ないか)
4. **スキャン演出** — 体感待ち時間のアンケート(実測時間は同じにする)

計測は既存の `usage_events` / `scan_events` に載せ、
管理画面(KPI)から見る。
