# キャッチの祝福の音 — 外部の AI や素材を使うときの手順（初心者向け）

最終確認: 2026-09-27

## いまの仕組み（前提）

- 祝福の音は **ファイルを使わず、アプリの中でその場で合成** しています（`src/lib/celebration-score.ts`、`src/lib/celebration-themes.ts`）。
  - 利点: 通信ゼロ・容量ゼロ・すぐ鳴る。
  - 弱点: 本物の楽器や声の「厚み」は出しにくい。
- 案は確認用ページ（Deploy Preview）の「キャッチの祝福（音と絵）」で聴き比べできます。
  - 音は A〜E（A 映画の山場＝今、B 軽快、C 温かい、D 静か、E これまで）。
  - はじけは 1〜4（光の輪・紙吹雪・星・なし）。

## 言葉の説明

| 言葉 | 意味 |
|---|---|
| 効果音（SFX） | 「ピコン」「シャラーン」のような短い音 |
| BGM | 後ろで流れる音楽 |
| ロイヤリティフリー | 一度許可を得れば、使うたびにお金を払わなくてよい |
| 商用利用 | お金を得るアプリ・サービスで使うこと |

## 手順（外部の AI で音を作る場合）

1. **使う道具を決める。** 例: ElevenLabs の Sound Effects（文章から効果音を作る）。
   - 公式の説明では、**有料プランなら商用利用可**、無料プランは非商用のみ。
   - 条件は変わることがあるので、使う前に必ず公式ページで最新の条件を確認してください:
     - https://elevenlabs.io/sound-effects
     - https://elevenlabs.io/terms-of-use
2. **作る音を1つずつ決める。** 今の演出で音が鳴るのは次の3か所です。
   - 頂点（写真が浮き上がって止まる瞬間）: 1秒以内
   - 二度目の山（語を読んだ後）: 0.5秒前後
   - 着地（図鑑に入る瞬間）: 0.3秒前後
3. **書き方の例（英語のほうが通りやすい）**
   - 頂点: `short bright magical success chime, sparkling, game reward, 0.8 seconds`
   - 着地: `soft wooden tap, gentle, satisfying, 0.3 seconds`
4. **書き出す。** 形式は `mp3`、音量はそろえる（大きすぎる音は割れます）。
5. **ファイルを渡す。** このチャットか PR に「頂点.mp3・着地.mp3」のように名前を付けて渡してください。
   - ファイルを鳴らす仕組みは、今はまだありません。受け取った時点でこちらで追加します（`public/sounds/` に置き、合成の代わりにファイルを鳴らす小さな変更）。
   - 通信で読み込むので、最初の1回だけ少し遅れることがあります。事前読み込みで対策します。

## 手順（素材サイトの音を使う場合）

- 「商用利用可」「クレジット表記不要」かどうかを、**そのサイトの利用規約で必ず確認**してください。
- 表記が必要な素材を使う場合は、設定画面などに出典を載せる必要があります。

## 注意（リスク）

- AI で作った音楽・効果音の権利の扱いは、サービスごと・時期ごとに違います。**規約を読まずに使わない**でください。
- 音が長いと、語の発音と重なって聞き取りにくくなります。語を読む間は自動で音量を下げていますが、効果音自体も短くしてください。
